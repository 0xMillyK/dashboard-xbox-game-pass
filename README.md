# 🎮 Dashboard Xbox Game Pass

## 📊 Sobre o projeto

Dashboard desenvolvido em Excel para análise de vendas e assinaturas do Xbox Game Pass.

O projeto foi desenvolvido a partir da proposta apresentada no curso da DIO e personalizado com análises adicionais para ampliar a interpretação dos dados e facilitar a visualização dos principais indicadores.

## 🎯 Objetivo

Analisar o comportamento das assinaturas do Xbox Game Pass, identificando diferenças entre os tipos de assinatura e observando indicadores relacionados ao faturamento, aos descontos e à adesão aos benefícios.

## 📈 Análises realizadas

- Quantidade de assinaturas por tipo;
- Faturamento por tipo de assinatura;
- Valor médio por assinatura;
- Média de cupom por tipo de assinatura;
- Adesão ao EA Play;
- Adesão ao Minecraft;
- Comparação entre assinaturas Annual, Monthly e Quarterly;
- Indicadores automáticos dos principais resultados.

## 🛠️ Ferramentas utilizadas

- Microsoft Excel
- Tabelas Dinâmicas
- Gráficos
- Fórmulas e funções do Excel
- Dashboard interativo

## 💡 Destaques

Além das análises propostas no curso, foram acrescentados indicadores e visualizações próprias para facilitar a interpretação dos dados e apresentar os resultados de forma mais clara e organizada.

## 📁 Arquivo

O arquivo `dashboard-xbox-game-pass.xlsx` contém o dashboard completo desenvolvido em Excel.
